1132 Fixer for Windows

Latest published build: 6.4.0, released 2026-09-05. Project requirements: Windows 10/11, x64, Zoom Workplace installed machine-wide, administrator approval, and Secondary Logon service. ARM64 native support is not verified.

Install Setup or use Portable from Windows 6.4.0 release notes. Run as administrator, read the checks, then press Fix now. Do not run while signed in as user1. Do not use on a managed computer without permission, or if user1 contains files you need.

Source workflow stops helper sessions, deletes the old user1 account and profile, creates a standard helper account with a fresh random password, starts installed Zoom as that account, and can create a desktop launcher. The helper password is sealed with Windows DPAPI (encryption tied to your Windows account) under %APPDATA%\1132 Fixer. The workflow also applies Zoom helper-profile settings and camera/microphone consent settings. Repair workflow; Credential storage.

Update checks use GitHub; older builds can use Botify or retired channels. Optional support uses a configured support endpoint, a per-install support reference, your report, and optional screenshot. Review reports before sending. Support network and identifiers. No automatic telemetry is claimed in project threat model; deployed server log retention remains unverified.

Rollback: close helper Zoom, sign in as a different administrator, remove the helper launcher, then remove user1 through Windows account management. Remove its old profile separately through System Properties > Advanced > User Profiles. This cannot restore deleted helper data or guarantee every applied system setting returns to its prior value. Back up required data first.

Troubleshooting: install machine-wide Zoom if it is not found; check Secondary Logon and administrator access; inspect camera/microphone privacy settings if devices are missing. A successful process launch does not prove Error 1132 is resolved.

Release 6.4.0 is unsigned. Do not treat SmartScreen as a verification failure to bypass blindly. Compare SHA-256 with published checksums and inspect release signature state.

These tools change local state. They cannot confirm why Zoom refused access, remove an account restriction, or guarantee recovery.
