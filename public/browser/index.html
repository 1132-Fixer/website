1132 Fixer for Browser

Store package: 1.2.1, updated 2026-08-06, from Chrome Web Store. Current public source: 1.2.7, browser repository. These are different builds. Last branded Chrome/Edge/Brave test date: not verified in this audit.

Store 1.2.1 describes cookie-only cleanup with cookies and activeTab permissions plus zoom.us/zoom.com host access. Current source 1.2.7 adds scripting to clear active Zoom-origin localStorage, sessionStorage, Cache API and IndexedDB. Do not assume source features are present in the store build. Current manifest.

Source requires Chrome 114+. Edge and Brave have Chromium package targets; exact branded versions remain unverified. Brave users can use the Chrome store package; Edge has no verified Add-ons listing. Firefox has separate source packaging; Safari is not implemented. Source compatibility matrix.

Open a Zoom tab, open the popup, and press FIX ZOOM. Detection alone does not clear anything. Both builds sign you out by deleting Zoom cookies; cookies can hold sign-in state, but this does not prove cookies caused Error 1132. Other sites are outside the intended scope. Manual alternative: use browser site settings to remove zoom.us and zoom.com data. Manual removal may be broader than cookie-only store cleanup.

Cleanup makes no direct request, but reloading Zoom loads its normal network resources. Source popup has no telemetry. Current source Report-a-Bug page checks service availability and can send your description, selected screenshot, version, user agent and per-install support reference on submission. Browser privacy policy; Cleanup implementation. The store description says no network requests; that is not a claim about all current source reporting features.

Reversal: sign into Zoom again and remove the extension through browser extension settings. Deleted cookies/site data cannot be restored by uninstalling. If FIX ZOOM is hidden, check active host and granted Zoom site access. If error remains, use official Zoom reporting. Source 1.2.7 automated checks passed on 2026-10-04: 45 unit tests and six end-to-end suites. Chromium 151.0.7922.34 and Firefox 153.0 were used. Cleanup tests use controlled browser API fixtures; they do not prove Zoom recovery. Branded Chrome/Edge/Brave runtime tests remain pending.

These tools change local state. They cannot confirm why Zoom refused access, remove an account restriction, or guarantee recovery. No current success rate or tested Zoom-version matrix is published here.
