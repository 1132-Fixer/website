Windows: separate local profile

Initial statemachine-wide Zoom installed; administrator signed in as someone other than user1.

Actionsstop helper sessions; reset user1 account and profile; create standard helper with random password; launch Zoom under that account; apply helper settings, consent entries and optional shortcut.

Permissions: administrator and Secondary Logon. Credential file: %APPDATA%\1132 Fixer\helper-credential.bin, protected by Windows CurrentUser DPAPI. Updates use GitHub; optional support sends reports to build-configured service.

Final stateZoom runs under helper profile if launch succeeds. This does not prove error recovery. Reversal removes helper account/profile and launcher; deleted data needs backup and changed consent/settings may need separate review.

macOS: local reset and sandbox

Initial stateinstalled Zoom, macOS 13+, available administrator approval.

Actionsclose Zoom and updater processes; stop/disable updater agents; check VPN/network; remove Zoom data/cache/preferences/logs/saved state from home Library; flush DNS; request camera/microphone access; launch Zoom under sandbox-exec. macOS 13 network repair may change and reconnect MAC address; macOS 14+ skips spoofing.

Network: GitHub update check; optional report sends system information and diagnostics to configured report endpoint. Source default: 1132-bug-report-production.up.railway.app.

Final statereset local session and sandboxed Zoom launch if steps pass. Reversal: quit and launch Zoom normally, restore needed data from backup, review updater agents/network changes. Uninstall does not restore deleted state.

Browser: explicit Zoom cleanup

Initial stateactive Zoom tab with browser cookies/site data. Detection clears nothing.

Actionpress FIX ZOOM. Store removes Zoom cookies; source additionally clears active Zoom-origin localStorage, sessionStorage, Cache API and IndexedDB. Then reload active tab. Other websites remain outside intended scope.

Permissions: cookies, activeTab, Zoom host access; source also scripting. Cleanup has no direct network request; tab reload loads Zoom resources. Optional source report page contacts project support service.

Final stateZoom browser sign-in state removed. Reversal: sign in again or remove extension. Deleted data cannot be restored by uninstalling. Cleanup status is not proof of Error 1132 recovery.
