1132 Fixer Safety, Licenses and Privacy

Windows and browser code use MIT licenses. Their names, logos and artwork have separate terms. macOS source is public under a noncommercial license; it is not open source under the usual definition. Free download does not grant commercial-use rights. Read license and safety details.

Download from project GitHub releases or the linked Chrome store only. Windows 6.4.0 signature-state.json reports UNSIGNED. macOS 1.7.6 DMG has a GitHub SHA-256 digest, and its app passed codesign verification and Gatekeeper assessment as Notarized Developer ID on 2026-10-04. A checksum checks byte identity; it does not prove the publisher is trustworthy. Versions and full digests.

Permissions and reversals differ. Windows requests administrator approval and changes user1/profile and consent/settings state. macOS resets local Zoom files, DNS and updater state, with administrator, camera and microphone permissions. Browser cleanup accesses Zoom cookies and active-tab state. Deleted data needs a prior backup to recover. See exact changes.

Destinations: GitHub/api.github.com for release checks and downloads; chromewebstore.google.com for store installation; zoom.us/zoom.com when Zoom runs or reloads; configured project support servers for optional reports. The browser source support origin is 1132-fixer-feedback-proxy-production.up.railway.app; macOS source default is 1132-bug-report-production.up.railway.app. Windows support destination depends on build configuration. No current endpoint reachability or server retention audit is claimed.

Reports can contain messages, diagnostics, system/version information, optional email or screenshots, and per-install support references in Windows/browser source. Windows support reference is encrypted using safeStorage where available. Current browser policy states screenshots are retained up to 90 days; this policy was read, not tested against the server. macOS diagnostics can contain local system information: review before sharing. Automatic crash reporting and deployed server IP/log retention are not verified.

Website privacy is separate: this site loads Umami via /x.js, uses umami.primehosting.dev, records download events with platform, variant and target URL, and loads Google Fonts. Discussions load comments.app only when opened. GitHub release checks expose your connection to GitHub. Servers can see your IP address; retention is not verified. This site is not telemetry-free. Website analytics server; Website requests.

Report vulnerabilities privately through the matching repository security policy: Windows security reporting, macOS security reporting, Browser security reporting. Do not post credentials or unredacted reports in public issues.

License texts: Windows MIT license, Browser MIT license, macOS noncommercial license. Brand rights are separate. This site makes no claim that publicly visible source grants unrestricted rights.
